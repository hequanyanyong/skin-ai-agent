🩺 AI 皮肤病灶初诊系统 (Skin AI Agent)
基于华为 CodeArts 智能体生态与盘古大模型打造的智能皮肤健康辅助诊疗系统

📌 项目简介
“AI 皮肤病灶初诊系统”是一款旨在提供高效、便捷、安全的皮肤健康预检与辅助决策系统。系统结合多模态患处图像识别与多轮智能问诊交互，帮助用户在就医前快速评估皮肤状况、获取分诊建议与护理指导，有效缓解用户健康焦虑，提升医疗分诊效率。

✨ 核心亮点
🔍 多模态视诊与问诊：支持上传患处照片并结合多选症状（发红、瘙痒、疼痛等），由 AI 进行综合特征分析。

🤖 多轮引导式追问：智能体根据初步识别结果主动发起针对性追问（如病程时长、接触史等），还原真实医生看诊逻辑。

📋 结构化健康预检报告：输出清晰包含“可能原因推测”、“推荐就诊科室”与“应急护理建议”的专业反馈。

🎨 人性化 Web 交互界面：采用现代医疗风格视效，提供独立滚动的局部交互体验与平滑流畅的对话响应。

🧭 项目使用流程
上传患处图像：在左侧区域点击或拖拽上传清晰的皮肤患处照片。

勾选伴随症状：勾选出现的主要体征（如发红、瘙痒、蜕皮等）。

交互式问诊：在右侧对话框中回复智能体提出的补充问题。

获取预检建议：智能体综合图像与问询信息，输出结构化初诊建议。
